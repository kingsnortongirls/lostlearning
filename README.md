# Lost Learning

A Computer Science catch-up website for pupils who have missed a lesson.

## Included
- Homepage and Year 7 Unit 1 lesson selector
- Lesson 1: Hardware (components, input/process/output, memory and storage)
- Lesson 2: Binary (place values, conversions, bits and bytes)
- Clear explanations, worked/model answers and self-marking quizzes
- Print-ready A4 worksheets labelled **Lost Learning - Catchup Work**
- Mobile-friendly, no login or external dependencies

## Publish using GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set branch to **main** and folder to **/(root)**, then save.
4. The expected website URL is https://kingsnortongirls.github.io/lostlearning/

## Future units
The `lessons` object in `index.html` contains lesson content and quiz answers. Add lesson records and adapt the worked-example renderer as new units are developed.

## Privacy
Quizzes are marked in the pupil's browser. No pupil names, responses or scores are sent to a server. Printable sheets are generated by the browser.

The first two lessons were written using the uploaded Year 7 Unit 1 teaching presentations, worksheets and answer keys. Original teacher answer files have not been published.
